🧪 Human vs AI — The Turing Test

How the Benchmark Works

Phase 1: Run Slither-only static analysis → baseline findings

Phase 2: Run Slither + LLM deep analysis → enriched findings

Phase 3: Compare results side-by-side

🔍 Slither-Only

Fast, deterministic, rule-based. Finds common patterns but misses context-dependent vulnerabilities.

🤖 Slither + AI

Understands business logic. Can identify false positives. Writes fix recommendations. Explains attack paths.

Command: mantle-audit benchmark -f contract.sol

💻 Demo Commands

# Full audit with AI analysis $ mantle-audit audit -f vault.sol -o report.html --format html # Quick static scan (no LLM) $ mantle-audit audit -f vault.sol --skip-llm --no-onchain # CI/CD integration $ mantle-audit audit -f vault.sol --ci --fail-on HIGH # Human vs AI benchmark $ mantle-audit benchmark -f vault.sol -o benchmark.json # Parse contract structure $ mantle-audit parse vault.sol

⛓️ On-Chain Integration

📄 AuditRegistry.sol

Custom smart contract on Mantle that stores audit records: contract hash, report hash, severity counts, timestamp.

📦 IPFS Storage

Full audit reports stored on IPFS via Pinata. On-chain only stores the hash — efficient and verifiable.
